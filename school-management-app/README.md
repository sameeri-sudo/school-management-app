# 🏫 Al-Madni School Management Portal

A modern, mobile-responsive full-stack school management web application built for stream-lining daily student attendance, teacher portals, headmaster approvals, and institutional analytics.

🔗 **[View Live Application](https://y-puce-nu-48.vercel.app)**

---

## ✨ Key Features

- **Role-Based Authentication**: Secure login tailored for the Headmaster (`hm`) and Class Teachers (`class1` through `class10`).
- **Teacher Attendance Portal**: Dedicated class-locked portals allowing teachers to record daily attendance, use quick-action toggles (Mark All Present/Absent), and submit records to the Headmaster.
- **Headmaster Approval Workflow**: Review teacher submissions, verify present/absent counts, and publish approved data directly to the school-wide summary.
- **Analytics & Overview Summary**: Comprehensive visual data and reports tracking school-wide attendance metrics.
- **Fully Mobile Responsive**: Optimized layouts designed using Tailwind CSS breakpoints to function seamlessly across mobile phones, tablets, and desktops.

---

## 🛠️ Tech Stack

- **Frontend**: React, Vite, Tailwind CSS
- **Backend & Database**: Supabase (PostgreSQL)
- **Deployment**: Vercel
